# Archive documentaire

Instantanés datés : audits, sessions, états des lieux et plans figés à un moment donné.
Ils sont conservés pour l'histoire du projet (utile pour le dossier et le jury CDA), mais
**ils ne pilotent plus rien**. En cas d'écart avec la réalité, ce sont les docs vivants du
dossier `instruction/` qui font foi, en particulier :

- `31_ETAT_REEL_2026-07-13.md` — l'état réel du code (fait foi)
- `24_ETAT_AVANCEMENT_VS_CDC` — le suivi CDC à jour
- `13_CLAUDE_LOG.md` — le journal chronologique
- `02_ROADMAP_GLOBALE`, `06_REGISTRE_TECHNIQUE`, `07_REGISTRE_SECURITE_RGPD`, `09_BACKLOG`

Rien n'est supprimé ici : on range, on ne jette pas.
